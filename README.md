# مكتبة العيسائي القانونية الرقمية — الإصدار 2

تطبيق PWA عربي يعمل دون إنترنت، بلا خادم. البيانات في IndexedDB على جهاز كل مستخدم.

## ما الجديد (كل شيء حقيقي)
- **سلة حقيقية** (استعادة/حذف نهائي/تفريغ) — كانت لا تُملأ أبداً.
- **محرر مستندات** يحفظ فعلاً في المكتبة، مع قوالب وطباعة وتنزيل Word ومسودة تلقائية.
- **مزامنة GitHub حقيقية** (Git Data API): نشر المكتبة العامة + نسخة احتياطية **مشفّرة AES-256** + استعادة.
- **كلمة مرور مُجزَّأة** (PBKDF2-SHA256، 250 ألف دورة) والرمز مشفّر بها. لا «إعادة ضبط» تتجاوزها.
- وضع زائر للقراءة فقط؛ أدوات التعديل لا تظهر إلا بعد دخول الإدارة (قفل تلقائي بعد 15 دقيقة).
- **مراسلة حقيقية** عبر واتساب/بريد (مع مشاركة الملفات حيث يدعم المتصفح) بدل «إرسال محلي» وهمي.
- بحث عربي مطبَّع (همزات/تاء مربوطة/تشكيل) عبر كل الأنواع مع تظليل.
- أمان: تعقيم HTML بقائمة بيضاء، بلا innerHTML على بيانات المستخدم، سياسة CSP صارمة.
- تصدير/استيراد كامل (مع المرفقات) ومشفّر اختيارياً. ترحيل تلقائي لبيانات النسخة القديمة.
- Service Worker بإصدارات وتحديث تلقائي، أيقونة maskable صحيحة.

## التشغيل المحلي
`python3 -m http.server 8080` ثم افتح http://localhost:8080

## النشر
ارفع محتويات هذا المجلد إلى جذر المستودع (استبدل الملفات القديمة واحذف README.txt) مع تفعيل GitHub Pages من الفرع main.

## نشر المحتوى للزوار
1. أنشئ Fine-grained token لهذا المستودع فقط بصلاحية **Contents: Read and write**.
2. الإدارة ← الإعدادات ← ربط GitHub ← الصق الرمز.
3. علّم العناصر «نشر للعامة» ثم ☁️ المزامنة والنشر ← نشر الآن. العناصر غير المعلّمة لا تُرفع أبداً.

## حدود يجب معرفتها
- المستودع عام، لذا النسخة الاحتياطية مشفّرة؛ اختر عبارة قوية ولا تفقدها (لا استرجاع لها).
- كلمة المرور تحجب واجهة الإدارة فقط؛ من يملك الجهاز يستطيع قراءة قاعدة المتصفح. للحماية الحقيقية للبيانات الحساسة لا تنشرها واعتمد النسخة المشفّرة.
